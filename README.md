# 🔍 Vodafone Fancy Numbers Bot - v2

بوت شغال 24/7 على Railway بلوحة تحكم كاملة على تيليجرام.

## المميزات
- فحص تلقائي كل X دقيقة (قابل للتعديل من تيليجرام مباشرة)
- زرار "افحص دلوقتي" للفحص الفوري
- عرض آخر نتيجة فحص
- إيقاف/استكمال الفحص التلقائي
- عرض حالة البوت اللحظية

## متغيرات البيئة المطلوبة
| المتغير | الوصف |
|---|---|
| `TELEGRAM_TOKEN` | توكن بوت تيليجرام |
| `CHAT_ID` | الـ chat_id بتاعك (للرسائل التلقائية) |

## الأوامر على تيليجرام
- `/start` أو `/menu` — يفتح لوحة التحكم
